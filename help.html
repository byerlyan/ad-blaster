Setup & training guide

Start with a reliable baseline. Teach Hybrid what your TV looks like.

The Legacy detector is the dependable starting point. Once it recognizes your channel consistently, collect real labels, train the optional classifier, and compare Hybrid in Shadow mode before allowing automatic muting.

⚠
Shadow mode is a hard no-control boundary. It never connects to Apple TV control, and both automatic and manual mute, unmute, and skip commands are blocked. Detection, labeling, and training continue normally.

Recommended path

From first setup to live control

Work through these steps in order. A clean Legacy baseline makes both your training data and Hybrid results easier to trust.

1

Finish the wizard

Select the capture card, pair Companion and AirPlay with Apple TV, and confirm a live frame is available.

2

Calibrate during programming

Create or select a profile while the channel logo and ordinary program content are visible. Do not calibrate during a commercial.

3

Run Legacy in Shadow

Choose Legacy, leave automatic muting off, enable Start in shadow mode, then watch at least one complete commercial break.

4

Correct and label

Use Activity to review transitions. In Settings, mark representative Content and Commercial windows across multiple viewing sessions.

5

Train and compare Hybrid

Export the labeled features, train the local model, enable the ML Classifier, and run Hybrid in Shadow mode.

6

Enable control conservatively

Only after Shadow results look correct, enable automatic muting. Start with the Conservative sensitivity preset.

Independent Apple TV actions

Choose muting and skipping separately

Detection decides whether the picture looks like a commercial. Two separate settings decide what The Clicker does about it.

Mute detected commercials

Works for both live and delayed playback and does not depend on playback-position metadata. pyatv restores the exact prior volume when absolute volume is supported, with button presses as a compatibility fallback.

Skip delayed commercials

Opt-in and delayed-only. The Clicker checks pyatv playback position before seeking. If the position is unavailable or playback is live, it suppresses the skip.

For mute-only operation: turn on Mute detected commercials and leave Skip commercials on delayed playback off. This works even while watching a recorded or time-shifted show.

Stable baseline

Using the Legacy system

Legacy detects commercial breaks from the calibrated visual signal—logo, color, or their combination—and adds debounce, recovery hysteresis, cooldown, and maximum-break safeguards.

Legacy remains useful after you train ML. It works without an audio input or model file, and it is the quickest way to diagnose capture, calibration, and profile problems.
ProfileUse it whenWhat to watch
LogoThe channel bug is stable during programming and disappears during ads.Score overlays, animated logos, and feeds where the logo remains during commercials.
ColorThe selected region has a consistent program palette.Scene changes or graphics that resemble the commercial palette.
ComboYou want logo and palette evidence to agree.Usually safer, but needs both references to be calibrated well.

Recommended Legacy check

  1. Open Calibration, select the channel profile, and verify Current resembles Template while programming is on.
  2. Open Settings, set Detection mode to Legacy, automatic muting off, and Start in shadow mode on.
  3. On Home, start the engine and watch the fused status through a program-to-commercial-to-program cycle.
  4. If it enters too easily, use Conservative or increase debounce. If it misses too much, try Balanced before changing individual thresholds.
  5. Use Disarm immediately if a live session controls volume incorrectly; this also starts the manual-override cooldown.

No persistent channel bug

Streaming shows without a logo

A missing logo is not commercial evidence by itself. Streaming episodes often fill the whole frame, so Logo mode has no stable program signal and should not be forced to behave like one.

Legacy

Use Color only when it separates

Create a separate Color profile for the service, show, or player layout. Prefer a small ROI only if it stays visually consistent during the program and changes during ads; otherwise use the full frame. Collect several Content and Commercial windows and use Suggest. If the reported distributions overlap heavily, Legacy visual detection is not reliable for that source.

Hybrid

Fuse independent streaming cues

Enable explicit ad-label/countdown OCR, audio transitions, a model trained on multiple episodes and breaks, and trusted fingerprints for repeated ads. If the Color profile creates false commercial evidence, turn off Hybrid Visual so it cannot dilute the better signals.

Recommended streaming recipe

  1. Create a Color Profile; do not create Logo or Combo unless a genuinely persistent program graphic exists.
  2. Run Legacy in Shadow and collect multiple separate Content and Commercial windows. Apply a suggested Color threshold only if the score ranges separate clearly.
  3. Switch to Hybrid, enable ad overlays and usable audio, and train ML from several episodes, menus, recaps, credits, and different ad breaks—not one adjacent run.
  4. Enroll fingerprints only for confirmed ads that repeat. A trusted fingerprint can classify by itself; OCR, audio transitions, and ML normally corroborate one another.
  5. If visual scores overlap, disable Hybrid Visual. Keep at least two useful corroborating sources available and validate complete breaks in Shadow mode.
Legacy has a real limit here. If arbitrary show scenes and ads have the same visual score distribution, no threshold can separate them reliably. Hybrid evidence is the correct fallback, not a more aggressive Logo threshold.

Local classifier

Training the model

The Clicker stores feature rows—not video—as you label. Training uses a small calibrated logistic-regression model designed to run locally on older hardware.

Good data

Collect varied sessions

Gather both Content and Commercial examples from different programs, channels, times, lighting/graphics conditions, and commercial breaks. Use at least four distinct marking sessions or sources.

Avoid leakage

Do not label one long adjacent run

Adjacent frames are very similar. Start and stop several separate marking windows so training, calibration, and test groups can remain independent.

1. Record labels in the dashboard

  1. Run the engine in Shadow mode with the correct channel profile.
  2. Open Settings → Tune Thresholds.
  3. During ordinary programming, select Mark Content; stop before a transition.
  4. During a confirmed ad, select Mark Commercial; stop before programming returns.
  5. Repeat in several separate sessions. The first and last second of each window are automatically trimmed.

2. Install the optional training tools

Install them into the same Python environment that runs The Clicker. On Intel macOS, do not use Monterey’s /usr/bin/python3 or Command Line Tools Python 3.9.

# Intel macOS / MacPorts installation
./venv-macports/bin/python3 -m pip install -r requirements-ml.txt

# Installed app on Apple silicon macOS or Linux
./venv/bin/python3 -m pip install -r requirements-ml.txt

# Source checkout (this repository)
./.venv/bin/python3 -m pip install -r requirements-ml.txt

3. Export and train

You can download the raw CSV from Home → Training & Trusted Ads, or run both commands locally:

# Source checkout: keep both commands in the same virtual environment
./.venv/bin/python3 scripts/export_feature_dataset.py --output data/features.csv

./.venv/bin/python3 scripts/train_commercial_model.py \
  --dataset data/features.csv \
  --output data/commercial_model.joblib

For an installed copy, replace ./.venv/bin/python3 with ./venv/bin/python3, or ./venv-macports/bin/python3 on Intel macOS. Use the same executable for installation, export, and training; the shell’s plain python3 may be Apple’s unrelated Command Line Tools Python.

The trainer requires both labels and enough distinct source/session groups to separate fitting, calibration, and testing. The saved artifact includes its schema, dataset digest, group assignments, precision, and recall.

4. Turn on the trained classifier

  1. Restart the service so it loads data/commercial_model.joblib.
  2. Open Settings → Advanced → Hybrid subsystems.
  3. Enable ML Classifier, save settings, and set Detection mode to Hybrid.
  4. Keep automatic muting off and compare at least several complete breaks in Shadow mode.
No model is bundled. If the file is missing, corrupt, or built with an incompatible feature schema, ML safely reports unknown and does not make a commercial decision.

Repeated advertisements

Enrolling trusted ads

Audio fingerprints help recognize a commercial you have already confirmed. They are separate from ML training and are never enrolled automatically.

  1. Enable Audio Fingerprints under Settings → Advanced, and make sure Hybrid Diagnostics reports audio available.
  2. While a confirmed commercial is playing, open Home → Training & Trusted Ads.
  3. Enter a useful ad name, choose a recent-audio duration—10 seconds is a sensible start—and select Enroll recent audio.
  4. Remove an enrollment if it matches programming or produces misleading results.

Only compact spectral tokens and metadata are stored in the local SQLite database; raw PCM audio is not written to disk.

Player-provided evidence

Flagging ad labels and countdowns

Hybrid can read player UI such as Ad 1 of 2, Advertisement 0:15, Commercial break, and Skip ad. Enable Ad labels & countdowns under Settings → Advanced.

Repeated confirmation

The label must be recognized in consecutive OCR scans. A short hold prevents one missed frame or a changing digit from dropping the flag immediately.

Corroboration required

The overlay supports logo, audio, fingerprint, or ML evidence. It cannot start a commercial classification by itself.

A timer alone is ignored. Sports clocks, news countdowns, and game-show timers are common. “Sponsored” alone is also only diagnostic and never an ad classification.

When the detector recognizes an overlay, Home → Hybrid Diagnostics shows the OCR text and remaining seconds. Run in Shadow mode first and confirm your service renders a stable explicit ad label.

Before live muting

Evaluate the result safely

The most important failure is muting programming. Compare modes on captured, labeled viewing rather than judging a model by overall accuracy alone.

Prefer precision

Review false-muted programming seconds per hour, especially around sports restarts, news graphics, and channel transitions.

Then improve coverage

Review commercial audio muted percentage and enter/exit latency. More aggressive thresholds can improve coverage at the cost of program safety.

For a prepared timestamp,label,legacy,hybrid CSV:

python3 scripts/evaluate_detection.py \
  --input evaluation.csv \
  --data-kind captured

When Hybrid performs worse than Legacy, keep using Legacy. More representative labels or a corrected calibration usually help more than simply lowering the commercial threshold.

Common problems

Troubleshooting

Legacy marks programming as a commercial

Confirm the active profile matches the current channel, recalibrate during stable programming, and try Conservative sensitivity. Inspect the Current and Template images for crop or logo changes.

The profile preview shows the FaceTime camera

The preview is the saved image from when that profile was calibrated; it is not a live camera view. Select the HDMI capture card in the wizard or Settings, then overwrite the affected profile. Calibration uses the saved device name and will now stop instead of silently falling back to FaceTime.

The model stays unavailable or unknown

Confirm data/commercial_model.joblib exists, restart the service, enable ML Classifier, and inspect Diagnostics for a schema or load error. Unknown is the expected safe state when a model cannot be used.

The trainer says there are not enough groups

Record more separate Content and Commercial marking windows. You need both labels and at least four distinct session/source groups; many adjacent rows from one window still count as one group.

Hybrid has no audio evidence

Open Settings → Advanced, refresh the Audio input dropdown, and choose the capture card’s audio interface. Restart the engine, then use Diagnostics to verify it. On macOS, a capture card may expose video under one device name and audio under another. Legacy visual detection can continue without audio.

Intel macOS shows no capture devices

Rerun bash deploy/setup-macos-intel.sh. On Monterey, allow The Clicker’s MacPorts Python process in System Preferences → Security & Privacy → Privacy → Camera, then restart the LaunchAgent. The device check now reports camera permission and AVFoundation backend failures separately.

Ad overlay OCR is unavailable

Install Tesseract, restart The Clicker, and verify tesseract --version works. The macOS and Debian deployment scripts install it automatically.

Automatic control made a bad decision

Select Disarm, turn automatic muting and skipping off, and return to Shadow mode. Review the active profile and Activity reason before changing thresholds or adding more training data.

The Clicker runs its detector, training data, model, and trusted fingerprints locally.
